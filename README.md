# 时薪 · 黄金 · 物价

**一小时的劳动，能换多少克黄金？这些黄金在当地又能买多少东西？**

这个项目用官方统计数据，把各经济体劳动者的购买力拆成三步来比较。所有经济体按同一套规则、同一种版式展示，默认不突出任何一个；读者可以自己选最多 8 个重点对比的经济体（点击排名图中的条形或名称、或“怎么算”表格中的名称即可），选中的经济体会出现在“经济体概况”里，列出它当年所用的各项工资口径、汇率、物价，以及哪些数据没有采用、为什么。默认展示二十国集团（G20）成员国，可切换到全部有数据的经济体；可在“按时薪”和“按月薪（不需工时假设）”之间切换，打开页面时默认显示 G20 成员国有数据更多的那一种（一样多时为按时薪）。某一参考年份能比较的经济体数量取决于各经济体数据的发布进度，页面会列出该年缺数据的经济体。

网站提供 14 种语言（覆盖全部 G20 成员国的主要语言，菜单按语言代码排序）：阿拉伯语（从右到左排版）、德语、英语、西班牙语、法语、印地语、印度尼西亚语、意大利语、日语、韩语、葡萄牙语（巴西）、俄语、土耳其语、简体中文。数据集里关于数据的每一句说明都以“消息编号 + 参数”发布，由网站按读者选择的语言渲染（`web/src/i18n/locales/*.json`，数量用各语言的复数规则）；英文为基准文本，其他语言由 AI 模型翻译并经第二遍独立审校，不是专业译者翻译。引用的 ILOSTAT 注释与调查名称保持其英文原文。

*English: hourly and monthly wages of every economy converted into grams of gold, what that gold buys locally (a healthy diet, household consumption at purchasing power parity), ICP 2021 price levels by category, and the gold price as a ruler that stretches — all from archived official sources, with the same rules and layout for every economy, in 14 languages.*

| 步骤 | 计算 | 说明 |
|---|---|---|
| ① 劳动 → 黄金 | 时薪 ÷ 当地金价 | 每小时工资能换多少克黄金 |
| ② 黄金 → 商品 | 当地金价 ÷ 当地物价 | 1 克黄金在当地能买多少（健康饮食天数 / 折合多少国际元） |
| ③ 劳动 → 商品 | ① × ② = 时薪 ÷ 物价 | 一小时劳动的真实购买力（黄金在这里被约掉） |

两个贯穿全站的结论：

1. **黄金不剥离汇率。** 各地金价 ≈ 美元金价 × 汇率，所以同一时点“克金时薪”之比等于按市场汇率换算的美元时薪之比。改变结论的是第②步——当地物价。
2. **价差主要在本地服务，不在食品。** 世界银行 ICP 2021 按统一规格比价：各经济体之间，食品价格水平的差距明显小于住房、医疗、教育等本地服务（网站“什么贵、什么便宜”一节由数据集算出各类价格水平的四分位距，并可选世界平均或任一经济体为比较基准）。

## 数据来源（全部为官方或国际组织发布）

| 数据 | 来源 | 用途 |
|---|---|---|
| 金价（月均） | 世界银行 Commodity Price Data（Pink Sheet）；IMF PCPS 交叉核对 | 当地金价 |
| 汇率、居民消费 PPP、人口；GDP 与居民消费的本币/美元/国际元值 | 世界银行 WDI | 换算与物价水平；后几项用于逐年核对汇率和 PPP 的货币单位、量级核对（人均 GDP）和连续性核对（名义人均收入） |
| 健康饮食成本（六类食物） | 世界银行 / FAO Food Prices for Nutrition | 统一口径的食物篮子 |
| 分类价格水平 | 世界银行 ICP 2021 | 食品、住房、医疗等各类价格水平（ICP 发布时以世界平均 = 100） |
| 全职当量平均年薪（现价与不变价、本币与 PPP 美元）、全职雇员通常周工时 | OECD Data Explorer | OECD 数据库中经济体的工资：在某一视图（时薪或月薪）下 ILOSTAT 没有注释未限定覆盖范围的数字时使用；时薪 = 全职当量年薪 ÷（OECD 全职雇员通常周工时 × 52） |
| 雇员平均/中位时薪与月薪（ILOSTAT 同时发布的本币、美元、PPP 三种值）、实际工时 | 国际劳工组织 ILOSTAT | 各经济体的工资（优先使用）与中位数；时薪折算用的同一调查工时 |
| 城镇私营单位就业人员年平均工资（年度公报） | 中国国家统计局 | 延续 ILOSTAT 中国序列（FX:216）ILOSTAT 尚未转载的年份 |
| 工资结构基本统计调查（賃金構造基本統計調査）表 1（一般劳动者、民营事业所、全行业）：所定内工资、所定内实际工时 | 日本厚生劳动省（e-Stat） | 延续 ILOSTAT 日本序列（DA:260）ILOSTAT 尚未转载的年份；同一张表的工时用于折算时薪 |

所有经济体的工资都来自同两个汇编（OECD、ILOSTAT），按同一条规则选用。国家统计机构自己的发布只在一种情况下读取：ILOSTAT 转载某个调查有滞后，而该调查的发布方已公布了同一序列更晚的年份，就用它延续 ILOSTAT 的序列（见下文“序列延续”）；不增加 ILOSTAT 没有的序列或口径。

每一次抓取的原始响应都**原样**保存在 `data/raw/`，`data/manifest.json` 记录了来源 URL、抓取时间（UTC）和 SHA-256；网站上的任何数字都能追溯到具体文件。

## 可信度设计

- **同期配对**：一年的工资只配同一年的平均汇率、平均金价和物价；月度数据只配同月均价。
- **自动校验**（`pipeline/wagegold/validate.py`）：世界银行与 IMF 金价交叉核对、金价数据新鲜度、美国 PPP 恒等于 1（ICP 的计价约定），以及计算本身的算术自检。任何一项失败，网站数据集都不会更新（原始快照与 `data/checks.json` 仍会提交，便于审计）。
- **同一参考年份**：跨国对比时所有经济体用同一年（默认是至少三分之二 G20 成员国有数据的最近年份）；金价几年内能翻倍，混用年份会让“克金工资”失真。该年缺可核对平均工资的经济体不出现在工资相关的图中（③ 中按食物类别拆分的图例外：分项成本只有基准年，该图用基准年及该年工资），并在页面上列出。
- **货币单位逐年核对**（`build.UnitGraph`）：每个数字都要把一家机构的数除以另一家机构的数，两者必须同一货币单位。汇率和购买力平价只用世界银行自己的数据核对，相差不超过 1.4 倍即视为同一单位（2002 年起货币单位改变至少会造成 1.42 倍的差，除非两个数同时因其他原因朝相反方向不同，这一点核对无法排除；而且只视为单位相同，不视为同一个数：财年换算或多重汇率下，官方汇率与世界银行换算 GDP 的因子会不同，网站上列出两者之比）：官方汇率 ≈ 世界银行 GDP 本币值 ÷ 美元值；PPP ≈ 居民消费本币值 ÷ 国际元值（世界银行缺这两项时，用 ICP 2021 的居民消费价格水平（相对美国）× 官方汇率核对 2021 年的 PPP）；其他年份在数值变化不超过 1.4 倍时沿用相邻年份的核对。工资和饮食成本再挂到通过上述核对的汇率或 PPP 上：健康饮食成本本币值 ÷ PPP 值 = PPP；ILOSTAT 工资本币值 ÷ 汇率（或 PPP）= ILOSTAT 自己的美元（或 PPP）换算值；OECD 不变价本币工资 ÷ PPP 美元值 = 基期 PPP（或 OECD 标注的货币与相符的 ILOSTAT 记录标注的货币一致）。发布方自己的换算只说明它用了同一个换算因子，不能用来核对汇率或 PPP；一条工资同时与一个通过核对和一个未通过核对的因子相符时，其货币单位视为无法确定；某年恒等关系不成立、但数值与已核对的年份逐年相差都不到 1.4 倍的，视为不是货币单位变化，原因不明，该年不使用（单列为“恒等关系不成立”，不算作单位无法确认）。未通过核对的输入不参与计算，剔除原因和数字列在网站“方法与来源”。不使用任何国家名单或静态货币表；容差 1.4 倍低于 2002 年以来所有非等值货币转换的倍数（最小的是拉脱维亚 2014 年加入欧元，1.42 倍）。2000–2001 年爱尔兰镑（与欧元固定汇率 1.27 倍）仍在流通，容差无法区分两者；本数据中爱尔兰这两年的数字来自 OECD，标注为欧元。
- **时间单位、数量级与连续性**：同一经济体同一年、已核对为同币种的数字之间互相核对。同一调查的月薪与时薪按该调查的实测工时折算应相差不超过 √(52/12) ≈ 2.08 倍（“周”与“月”之比的对数中点），且月薪 ÷ 时薪在 1–744 小时之间；该调查没有工时的，用该年其他来源每周工时的中位数（含 OECD 全职雇员通常工时）折算，相差达到 4.33 倍才算有误。不同来源的同一种平均数（或中位数）：相差 2.08 倍以内互相佐证；达到 4.33 倍（一个“周”与“月”之差）算单位或数量级错误；介于两者之间时口径差异（例如 OECD 全职当量工资与住户调查平均工资）与时间单位错误无法区分，数字保留并注明无法确认。一个月的工资高于人均全年 GDP、或低于人均一周的居民消费的，视为时间单位或数量级无法确定，同一调查同一时间单位的数字都不用。工时本身也核对：每周 0–168 小时，并与同年其他来源的工时（含 OECD）相差不超过 2.08 倍；同年没有其他来源时，才与同一序列相邻年份比。一个数字的数量级只能由其他来源佐证（同一调查的月薪与时薪来自同一批数据）。对不上时，由另有佐证的一方决定；只能互相矛盾时，逐对看各自序列的相邻年份是否也相差同一量级；仍无法判断就一并不用。同一来源两个年份之间的变化，分别与同期名义人均居民消费和人均 GDP（世界银行本币值 ÷ 人口）的变化相比，偏离超过 OECD 同口径平均工资在同样年数或更短时间内相对同一参照出现过的最大偏离（每次运行由存档数据按参照和相隔年数算出），且对每个可用参照都超出时，在说明中注明，历年曲线在那里断开；口径注释不同或注明序列中断的两年，相差超过 2.08 倍才注明。
- **按发布方的注释判定口径**：ILOSTAT 每条记录的注释和观测状态（中位数/均值、名义/实际值、最低工资、时间单位、地区/规模/部门/行业/人群/全职等覆盖范围、序列断点、“不可靠”）决定它算作什么、能否换算、排在哪一位；没有限定覆盖范围的注释的记录视为覆盖全体雇员；地理覆盖注释除非写明全国且无任何地区除外（海外领地除外：世界银行将其列为单独的经济体），否则视为限定，最高年龄限制也视为限定，最低年龄（各调查统计雇员的起始工作年龄）不算。可用但未被选中的同类记录也列入剔除记录，并写明选了哪一个。选用顺序对所有经济体相同，先看覆盖范围、再优先覆盖经济体最多的汇编：ILOSTAT 中未限定覆盖范围的记录 → OECD 全职当量工资 → ILOSTAT 覆盖范围有限的记录（网站标注“覆盖范围有限”）。同一经济体同一年两者都有时，ILOSTAT 调查的平均工资多数低于 OECD 全职当量工资（网站给出由数据算出的中位比值），所以 OECD 不排在前面，以免 OECD 成员整体换成另一种口径。时薪视图与月薪视图各自按这个顺序取第一个存在的数字。
- **序列延续**（`build.UnitGraph._extend`）：发布方读取器提供的序列必须与 ILOSTAT 的同一序列在两者都有的每一年相差不超过 1%（国家统计局 2020–2022 年与 ILOSTAT 相差不到 0.01%，厚生劳动省 2020–2021 年与 ILOSTAT 完全相同），否则整条不用；只补 ILOSTAT 最新年份之后的年份，沿用该序列的口径注释；货币单位只有在与该序列上一年相比变化不超过 1.4 倍时才沿用，之后与其他数字一样经过全部核对。发布方注明当年口径变化的（如国家统计局按“可比口径”另算增速的 2024 年，第五次经济普查后纳入小微企业），该年标为序列断点。唯一不在 ILOSTAT 中的是工时：ILOSTAT 没有该调查的工时、而发布方同一张表给出了工时时，用它把月薪折算为时薪，工时同样要经过工时核对。
- **可复现**：data-refresh 在联网生成数据集后，只用刚存档的快照离线重算一遍，结果必须完全一致。
- **结论由数据计算**：网站文字里的数字（如各类价格水平的四分位距、汇率与 GDP 换算因子的最大差距、金价涨幅）都由数据集计算，数据刷新后随之改变。
- **中立**：判断规则只看数值，不针对任何特定国家；没有默认的“本国”，也没有以某一国为基准的图（ICP 的国际元按定义以美国物价为基准，这是计价单位的约定，网站上注明）。
- **不推测**：缺少同年工时就不折算时薪；商品价格只用按统一规格比价的官方数据（ICP、健康饮食成本），不拿规格不同的单品价格跨国比较。

## 目录结构

```
pipeline/            Python 数据管道（只用标准库 + openpyxl）
  wagegold/fetch.py      抓取与快照存证（按主机熔断、失败时沿用上次快照并标记 stale）
  wagegold/sources/      各数据源的抓取与解析
  wagegold/build.py      由原始数据得出的全部数字（网站只在这些数字上做展示用的换算与比值，如四分位比、指数、按市场汇率的美元值）
  wagegold/validate.py   跨来源校验
  tests/                 单元测试
data/
  raw/                   官方原始响应（逐字节）
  manifest.json          每个快照的 URL / 时间 / SHA-256
  checks.json            最近一次校验结果
web/                 网站（Vite + React + TypeScript + ECharts）
  public/data/dataset.json   管道产出的数据集（说明文字为语言无关的消息编号 + 参数）
  src/i18n/locales/          各语言的文字目录；scripts/check-i18n.mjs 在每次构建前检查各语言的键、占位符与复数形式，以及代码里直接写出的键、管道中 M("…") 写出的字面量键（每个 f-string 键模式至少要对应一个目录键），和数据集里出现的每个消息键
.github/workflows/
  data-refresh (data.yml)    抓取 → 校验 → 生成数据集 → 提交
  pages (pages.yml)          构建网站并发布到 GitHub Pages
  ci (ci.yml)                单元测试、网站构建（离线重算的可复现性检查在 data-refresh 里）
```

## 如何刷新数据

- **自动**：`data-refresh` 工作流在默认分支上每天 07:23 UTC 运行；管道代码变更时也会自动运行。
- **手动**：打开仓库的 **Actions** 页面 → 左侧选 **data-refresh** → 点 **Run workflow**。

## 本地运行

```bash
# 数据管道（联网抓取；--offline 则只用已提交的快照重算）
pip install -e "pipeline[test]"

# 网站
cd web
npm ci
npm run dev                   # 开发预览
```

在仓库 **Settings → Pages** 中将 **Source** 设为 **GitHub Actions**，之后默认分支上的 `pages` 工作流会自动构建并发布。

## 局限

- 平均工资受高收入者影响；有中位数的经济体会同时展示。
- ILOSTAT 汇总各国口径（税前/税后、是否含奖金等）并不完全一致，网站在每条记录上标注来源。
- “最低成本健康饮食”只覆盖食物且选最便宜的组合；住房、医疗、教育、社保等决定生活质量的大项需要结合 ICP 分类价格与购买力平价一起看。
- ICP 分类价格是 2021 年基准年的结构；整体物价水平使用世界银行逐年外推的官方 PPP。本项目只存档了 ICP 2021 的逐项比价，2021 年之后各类食品的确切价差本项目给不出。
- 所有经济体都依赖 ILOSTAT 与 OECD 的汇编，它们转载各经济体官方数据有滞后，最近年份可能缺失，页面会列出缺数据的经济体。目前已用发布方自己的数据延续的：中国（国家统计局，到 2025 年）、日本（厚生劳动省，到 2025 年）。G20 中下列序列无法这样延续：澳大利亚（ILOSTAT 用 HILDA 住户调查的微观数据自行计算）、德国（月薪为 EU-SILC 微观数据计算；时薪来自四年一次的收入结构调查）、南非（NIDS 面板调查已结束）、印度尼西亚（统计局公布的平均工资与 ILOSTAT 由微观数据计算的数在重合年份相差 7%–15%，不是同一序列）、沙特阿拉伯（统计局劳动力调查 2022 年第四季度全体受雇者平均月薪为 5,838.5 里亚尔，ILOSTAT 同期为 6,748 里亚尔且注明只含全职雇员，统计局的表中没有与之相等的数）、韩国（ILOSTAT 序列为 5 人以上事业所的口径，雇佣劳动部的年报是 PDF，本项目没有找到可机读、能与 ILOSTAT 核对一致的同一序列）、俄罗斯（联邦统计局网站的 TLS 证书不在通用的根证书库中，自动抓取在证书校验时失败，本项目不关闭证书校验）。
- 健康饮食成本只在 ICP 基准年逐项定价；按世界银行的说明，其他年份由基准年成本按消费价格指数推算，六类食物的分项也只有基准年。
- 时薪有三种来源：ILOSTAT 直接按小时发布的；用同一调查的工时（ILOSTAT 发布的，或发布方同一张表的）由月薪折算的；OECD 全职当量年薪按 OECD 全职雇员通常周工时折算的。某年三者都没有的经济体只出现在“按月薪”视图里（例如中国：国家统计局的平均工资不附工时）。
- 译文由 AI 模型生成并经第二遍独立审校，可能有不够地道之处；数据与原文引用不受翻译影响。
