# 时薪 · 黄金 · 物价

**一小时的劳动，能换多少克黄金？这些黄金在当地又能买多少东西？**

这个项目用官方统计数据，把各国劳动者的购买力拆成三步来比较。默认展示二十国集团（G20）成员，可切换到全部有数据的经济体（数据集收录 192 个经济体，其中 172 个至少有一年可核对的工资数据；某一参考年份能比较的数量取决于各国发布进度，例如 2024 年按月薪约 78 个）。可在“按时薪”和“按月薪（不需工时假设）”之间切换。

| 步骤 | 计算 | 说明 |
|---|---|---|
| ① 劳动 → 黄金 | 时薪 ÷ 当地金价 | 每小时工资能换多少克黄金 |
| ② 黄金 → 商品 | 当地金价 ÷ 当地物价 | 1 克黄金在当地能买多少（健康饮食天数 / 美国物价下的等值美元） |
| ③ 劳动 → 商品 | ① × ② = 时薪 ÷ 物价 | 一小时劳动的真实购买力（黄金在这里被约掉） |

两个贯穿全站的结论：

1. **黄金不剥离汇率。** 各地金价 ≈ 美元金价 × 汇率，所以同一时点“克金时薪”之比等于按市场汇率换算的美元时薪之比。改变结论的是第②步——当地物价。
2. **超市食品不是各国价差最大的地方。** 世界银行 ICP 2021 按统一规格比价（按市场汇率，美国 = 1）：中高收入、中低收入、低收入经济体的食品价格水平中位数约为 0.78、0.76、0.72，而住房只有 0.23、0.16、0.15——便宜的主要是服务。中国 2021 年食品整体为美国的 1.12 倍，住房 0.32、医疗 0.31。

## 数据来源（全部为官方或国际组织发布）

| 数据 | 来源 | 用途 |
|---|---|---|
| 金价（月均） | 世界银行 Commodity Price Data（Pink Sheet）；IMF PCPS 交叉核对 | 当地金价 |
| 汇率、居民消费 PPP、人口；GDP 与居民消费的本币/美元/国际元值 | 世界银行 WDI；ECB 参考汇率、美联储 H.10 交叉核对 | 换算与物价水平；后三项只用于逐年核对汇率和 PPP 的货币单位 |
| 健康饮食成本（六类食物） | 世界银行 / FAO Food Prices for Nutrition | 统一口径的食物篮子 |
| 分类价格水平 | 世界银行 ICP 2021 | 食品、住房、医疗等各类价格与美国对比 |
| 全职当量平均年薪（现价与不变价、本币与 PPP 美元）、全职雇员通常周工时 | OECD Data Explorer | OECD 数据库中经济体的工资（优先使用） |
| 雇员平均/中位时薪与月薪（ILOSTAT 同时发布的本币、美元、PPP 三种值）、实际工时 | 国际劳工组织 ILOSTAT | 其他经济体的工资 |
| 美国时薪（1964 年起）、超市单品均价 | 美国劳工统计局 BLS API；FRED 交叉核对 | 美国细项 |
| 中国城镇单位平均工资、农民工收入、企业周平均工作时间、居民消费价格月度发布 | 国家统计局数据发布 | 中国细项；CPI 发布按原文摘录同比句子，用于核对相关说法 |

每一次抓取的原始响应都**原样**保存在 `data/raw/`，`data/manifest.json` 记录了来源 URL、抓取时间（UTC）和 SHA-256；网站上的任何数字都能追溯到具体文件。

## 可信度设计

- **同期配对**：一年的工资只配同一年的平均汇率、平均金价和物价；月度数据只配同月均价。
- **跨来源校验**（`pipeline/wagegold/validate.py`）：世界银行与 IMF 金价、ECB 与美联储汇率、BLS 与 FRED、国家统计局前后年份与增速、ILOSTAT 与国家统计局、恒等式等。任何一项失败，网站数据集都不会更新（原始快照与 `data/checks.json` 仍会提交，便于审计）。
- **同一参考年份**：跨国对比时所有经济体用同一年（默认是至少三分之二 G20 成员有数据的最近年份）；金价几年内能翻倍，混用年份会让“克金工资”失真。该年缺数据的经济体不出现在图中，并在页面上列出。
- **货币单位逐年证明**（`build.UnitGraph`）：每个数字都要把一家机构的数除以另一家机构的数，两者必须同一货币单位、汇率必须是该年实际用于换算的汇率。每个经济体每一年，只有下列恒等关系成立时才认为同一单位：官方汇率 = 世界银行 GDP 本币值 ÷ 美元值；PPP = 居民消费本币值 ÷ 国际元值；健康饮食成本本币值 ÷ PPP 值 = PPP；ILOSTAT 工资本币值 ÷ 汇率（或 PPP）= ILOSTAT 自己的美元（或 PPP）换算值；OECD 不变价本币工资 ÷ PPP 美元值 = 基期 PPP；国家统计机构标明的货币 = 上述已证明的货币。证明不了的输入不参与计算，剔除原因和数字列在网站“方法与来源”。不使用任何国家名单或静态货币表；容差按真实存在的最小货币改值倍数（拉脱维亚 1.42 倍）设定。
- **按发布方的注释判定口径**：ILOSTAT 每条记录的注释（中位数/均值、名义/实际值、时间单位、只覆盖城镇或私营部门、序列断点）决定它算作什么、能否换算、排在哪一位；国家统计局工资的统计范围和“可比口径”说明原文写入说明。
- **可复现**：data-refresh 在联网生成数据集后，只用刚存档的快照离线重算一遍，结果必须完全一致。
- **结论由数据计算**：网站上“核对之前的说法”等文字结论都由数据集计算得出（例如 BLS 是否仍标注为初值、CPI 原文是否含对应数字），数据刷新后会随之改变。
- **不推测**：缺少同年工时就不折算时薪；没有官方单品零售价（中国）就不做“同名商品”比价，并说明依据。

## 目录结构

```
pipeline/            Python 数据管道（只用标准库 + openpyxl）
  wagegold/fetch.py      抓取与快照存证（按主机熔断、失败时沿用上次快照并标记 stale）
  wagegold/sources/      各数据源的抓取与解析
  wagegold/build.py      全部计算（网站只展示，不推导新数字）
  wagegold/validate.py   跨来源校验
  tests/                 单元测试
data/
  raw/                   官方原始响应（逐字节）
  manifest.json          每个快照的 URL / 时间 / SHA-256
  checks.json            最近一次校验结果
  derived/               由管道生成的辅助索引（国家统计局价格类发布目录、CPI 同比原句摘录）
web/                 网站（Vite + React + TypeScript + ECharts）
  public/data/dataset.json   管道产出的数据集
.github/workflows/
  data-refresh (data.yml)    抓取 → 校验 → 生成数据集 → 提交
  pages (pages.yml)          构建网站并发布到 GitHub Pages
  ci (ci.yml)                单元测试、离线重算、网站构建
```

## 如何刷新数据

- **自动**：`data-refresh` 工作流在默认分支上每天 07:23 UTC 运行；管道代码变更时也会自动运行。
- **手动**：打开仓库的 **Actions** 页面 → 左侧选 **data-refresh** → 点 **Run workflow**。
- 可选：在仓库 Settings → Secrets 中添加免费的 `BLS_API_KEY`，可提高美国劳工统计局 API 的每日额度（未设置时用匿名额度，目前每次运行约 9 次请求）。

## 本地运行

```bash
# 数据管道（联网抓取；--offline 则只用已提交的快照重算）
pip install -e "pipeline[test]"
python -m pytest pipeline -q
python -m wagegold            # 或 python -m wagegold --offline

# 网站
cd web
npm ci
npm run dev                   # 开发预览
npm run build                 # 产出 web/dist
```

## 发布网站

在仓库 **Settings → Pages** 中将 **Source** 设为 **GitHub Actions**，之后默认分支上的 `pages` 工作流会自动构建并发布。

## 局限

- 平均工资受高收入者影响；有中位数的经济体会同时展示。
- ILOSTAT 汇总各国口径（税前/税后、是否含奖金等）并不完全一致，网站在每条记录上标注来源。
- “最低成本健康饮食”只覆盖食物且选最便宜的组合；住房、医疗、教育、社保等决定生活质量的大项需要结合 ICP 分类价格与购买力平价一起看。
- ICP 分类价格是 2021 年基准年的结构；整体物价水平使用世界银行逐年外推的官方 PPP。2021 年之后各类食品的确切价差没有官方逐项比价。
- 中国没有全体雇员的单一平均工资；时薪按企业就业人员周平均工作时间折算，工时与工资统计的覆盖面不完全一致。
- 部分经济体没有与工资同口径的工时数据（如日本），或近年缺少（如韩国 2023 年起），这些年份只出现在“按月薪”视图里；部分 G20 成员近年的工资尚未发布到 ILOSTAT/OECD，页面会列出。
